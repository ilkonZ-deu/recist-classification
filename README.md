# Классификация медицинских заключений по критериям RECIST

Курсовая работа, НИУ ВШЭ, ФКН (программа «Финансовые технологии и анализ данных»).

Автоматическое определение категории ответа опухоли на лечение
по тексту радиологического заключения на русском языке.

## Задача

По свободному тексту заключения (МРТ/КТ) определить категорию ответа
на лечение по критериям RECIST и заполнить два поля для неразмеченных
данных:

- `result` — 4 класса: полный ответ, частичный ответ, стабилизация
  заболевания, прогрессирование заболевания;
- `result_general` — 3 укрупнённых класса (полный и частичный ответ
  объединены в «ответ на лечение»); выводится из `result` по иерархии.

Из 7482 заключений 2307 размечены и используются для обучения и оценки,
оставшиеся 5175 размечаются обученной моделью.

## Подходы

Сравниваются три классификации текста:

1. **Baseline** — TF-IDF + логистическая регрессия;
2. **Дообученные трансформеры** — RuBioRoBERTa (доменная) и
   ruRoBERTa-large (общеязыковая);
3. **Большие языковые модели (few-shot)** — gpt-oss-20b и gpt-oss-120b
   через Groq, без дообучения.

## Результаты

macro-F1 на отложенном тесте (разбиение на уровне пациента):

| Модель | Подход | macro-F1 |
|---|---|---|
| ruRoBERTa-large | общий трансформер | 0.668 |
| RuBioRoBERTa | доменный трансформер | 0.614 |
| TF-IDF + LogReg | классический ML | 0.611 |
| gpt-oss-20b | LLM, few-shot | 0.424 |
| gpt-oss-120b | LLM, few-shot | 0.396 |

Основные выводы: few-shot LLM заметно уступают обучаемым моделям и не
распознают редкие классы; на малой несбалансированной выборке baseline
и трансформеры сопоставимы, но трансформеры устойчивее на редких классах
